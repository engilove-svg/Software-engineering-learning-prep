Topic: for and while Loops
1. for Loop

Use a for loop when you know the range/sequence you want to go through.

for i in range(1, 6):
    print(i)

Output:

1
2
3
4
5
range()
range(start, stop, step)

Examples:

range(5)          # 0, 1, 2, 3, 4
range(1, 6)       # 1, 2, 3, 4, 5
range(1, 10, 2)   # 1, 3, 5, 7, 9
range(10, 0, -1)  # 10, 9, 8, ..., 1

Important: stop is excluded.

2. while Loop

Use a while loop when you want to keep repeating while a condition is true.

i = 1

while i <= 5:
    print(i)
    i += 1
Three things to identify
Starting value
      ↓
Condition
      ↓
Update

Example:

i = 1              # start

while i <= 5:      # condition
    print(i)
    i += 1         # update
⚠️ Infinite loop
i = 1

while i <= 5:
    print(i)

This is infinite because i never changes.

3. Counter

A counter keeps track of how many times something happens.

count = 0

for i in range(5):
    count += 1

print(count)

Output:

5
4. Accumulator

An accumulator builds a result.

total = 0

for i in range(1, 6):
    total = total + i

print(total)

Output:

15

Remember:

total = i

replaces the value.

total = total + i

adds to the existing value.

5. break

Stops the loop completely.

for i in range(1, 11):
    if i == 6:
        break
    print(i)

Output:

1
2
3
4
5
6. continue

Skips the current iteration.

for i in range(1, 11):
    if i == 5:
        continue
    print(i)

Output:

1
2
3
4
6
7
8
9
10
