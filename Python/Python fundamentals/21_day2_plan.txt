means assign 23 to age.

age == 23

means check whether age is 23.

🧩 4. DSA — 2 Easy Problems

Today's tracker requires 2 easy problems.

Problem 1 — Two Sum

Given:

nums = [2, 7, 11, 15]
target = 9

Return the indices of the two numbers that add up to the target.

Expected:

[0, 1]

Try it yourself first.

After solving, answer:

What is the brute-force approach?
What is its time complexity?
Can you solve it using a dictionary?
Why is the dictionary approach faster?
Problem 2 — Contains Duplicate

Given:

nums = [1, 2, 3, 1]

Return:

True

because 1 appears twice.

Test:

[1,2,3,4] → False
[1,1,2,3] → True
[5,6,7,8,9] → False

After solving, explain:

Why is a set useful for this problem?
